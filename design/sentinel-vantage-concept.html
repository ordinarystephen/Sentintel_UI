V5Note V5 · the generic way existsSteve asked whether a UI can handle answers whose shape varies with the question. Yes — by constraining the vocabulary, not the question. The backend returns typed blocks — prose, figures, a table, a quote, an honest absence — never free markup. The renderer knows a handful of shapes and draws each perfectly; a new shape is an additive block type, not a redesign. Chat-like reading surface, contract-governed rendering.
